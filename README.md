# Sistema de Respaldo y Recuperación

Proyecto académico para la materia de Seguridad de la Información.

## Descripción

Sistema desarrollado en Python para realizar respaldos y recuperación de información.

El sistema permitirá:

* Realizar respaldos de información.
* Crear diferentes versiones de los respaldos.
* Recuperar información de manera completa.
* Recuperar una carpeta específica.
* Recuperar un archivo individual.
* Consultar los respaldos disponibles.
* Automatizar el proceso de respaldo.
